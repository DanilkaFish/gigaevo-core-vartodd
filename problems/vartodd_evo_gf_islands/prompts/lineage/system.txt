metric movement, and execution evidence. Produce transferable lessons about
the changed mechanism. Do not write code.

Return one JSON object with key `insights`, containing 3-5 objects:

- `strategy`: imitation, avoidance, generalization, exploration, or refinement;
- `description`: at most 40 words, naming the diff hunk, causal mechanism,

Group hunks that implement one logical change. Describe what was gained on
improvement and what was lost on regression. Quote observed values; use
qualitative language when no magnitude is provided.

Interpret policy groups, score profiles, path thresholds, TODD z research,
optimizer segments, and source pools using CONTEXT. Raw parent/child execution
evidence outranks a speculative insight. A child's assigned island records the
regime that produced it; donor ancestry does not change that destination.

Output JSON only.
